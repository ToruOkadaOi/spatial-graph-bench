# Source data and attribution

The corrected benchmark uses these publicly accessible source datasets. This benchmark release is shared under **CC BY 4.0**. Please cite the benchmark and the relevant source record when reusing its materials.

| Dataset | Source and reuse information |
| --- | --- |
| MERFISH spinal cord | [Zenodo record](https://zenodo.org/records/20533289). Open access. Cite the record and its associated study. |
| Open-ST lymph node | [GEO GSE251926](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE251926). Public. GEO states that it places no restrictions on use or distribution, while noting that submitters may retain intellectual-property rights. See the [GEO disclaimer](https://www.ncbi.nlm.nih.gov/geo/info/disclaimer.html). |
| Xenium mouse kidney | [Figshare 28761695, version 2](https://doi.org/10.6084/m9.figshare.28761695.v2). CC BY 4.0; credit the source and indicate changes. |
| Stereo-seq axolotl | [STOmicsDB STDS0000056](https://db.cngb.org/stomics/datasets/STDS0000056/summary). Public dataset. Cite the accession and associated study. |

The release contains processed features, graphs, model outputs, and reproduction materials; it does not include the original raw source-data files.
